StrokePredict 1.0
======================================================

StrokePredict is a Python program estimating the user's current risk of stroke and predicts possible future risk levels.

DISCLAIMER:
Application has been created for educational and research purposes only. Predictions generated by the program may be inaccurate and cannot serve as medical advice, diagnosis, or treatment information.

======================================================

Requirements:

python 3.13.9
pandas
numpy
matplotlib
scipy
scikit-learn

======================================================

Installation:

Install required libraries using pip
pip install pandas numpy matplotlib scipy scikit-learn

======================================================

Application Startup:

Open terminal
Change directory to the StrokePredict folder
Run the application by command python main.py or python3 main.py

======================================================

Data source:

https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset
